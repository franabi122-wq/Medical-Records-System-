                            Hospital Medical Records Management System (MRMS)

A web-based healthcare information management project developed to explore digital medical records management, data organisation, and patient information privacy.

📌 Project Overview

The Hospital Medical Records Management System (MRMS) is a web development project created to demonstrate how web technologies can support the organisation and management of healthcare information.

The project was developed using PHP for backend development and Microsoft SQL Server for database management. It incorporated a customised Medilab Bootstrap template alongside components from an existing open-source Human Resource Management System (HRMS) project.

I personally customised the Medilab template, integrated components from the existing HRMS project, and modified the PHP functionality to adapt the application to its intended medical records management context.

The integration and customisation work formed part of the project's development and presentation.

🎯 Project Objectives

- Explore digital approaches to medical information management.
- Promote organised handling of healthcare information.
- Emphasise the importance of data accuracy.
- Recognise the importance of patient information privacy.
- Apply web development technologies to a healthcare-related use case.
